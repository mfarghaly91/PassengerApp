STEP 2 — Backend API

Create a new route file for rides. Register it in the main router. Use existing auth middleware. Wrap every endpoint in try/catch. Validate every request body with Zod. Use Drizzle ORM only, no raw SQL.

For distance calculation use the Haversine formula implemented inline. Do not install any package for it.

Price formula: estimatedPrice = max(minimumFare, baseFare + distanceKm * perKmRate)

Endpoints to create:

GET /admin/rides/pricing — return pricing for car and bike. Admin only.
PATCH /admin/rides/pricing/:vehicleType — update pricing fields for car or bike. Admin only.
GET /admin/rides — list all rides with filters (vehicleType, status, driverId, passengerId) and pagination. Admin only.
GET /admin/rides/:id — full ride detail including passenger info, driver info, and all ride_events. Admin only.

POST /rides/estimate — body: { vehicleType, pickupLatitude, pickupLongitude, dropoffLatitude, dropoffLongitude } — calculate and return distanceKm, estimatedDurationMinutes, estimatedPrice. Auth: any logged in user.
POST /rides/request — body: { vehicleType, pickupLatitude, pickupLongitude, pickupAddress, dropoffLatitude, dropoffLongitude, dropoffAddress } — check passenger wallet balance is enough, create ride with status 'searching', insert RIDE_REQUESTED into ride_events, emit socket event ride:new_request to room drivers:available:{vehicleType}. Auth: user role only.
GET /rides/my — passenger's own ride history, filterable by vehicleType and status, paginated. Auth: user.
GET /rides/:id — get ride. Passenger sees only their own. Driver sees only theirs. Admin sees all. Auth: any.
PATCH /rides/:id/cancel — passenger cancels. Only if status is requested, searching, or driver_assigned. Sets cancelled_at, cancel_reason = passenger_cancelled. Emits ride:cancelled socket event to the driver if one was assigned. Auth: user, must own ride.

GET /driver/rides/available — rides with status 'searching' matching this driver's vehicle_type. Driver must be online. Auth: driver.
PATCH /driver/rides/:id/accept — check ride is still 'searching'. Set status to driver_assigned, set driver_id, set driver_assigned_at, set driver status to busy. Insert DRIVER_ASSIGNED event. Emit ride:driver_assigned socket event to passenger. Auth: driver.
PATCH /driver/rides/:id/arrived — set status to driver_arrived, set driver_arrived_at. Insert DRIVER_ARRIVED event. Emit ride:driver_arrived to passenger. Auth: driver.
PATCH /driver/rides/:id/start — set status to active, set started_at. Insert RIDE_STARTED event. Emit ride:started to passenger. Auth: driver.
PATCH /driver/rides/:id/complete — calculate final_price. In a DB transaction: set status to completed, set completed_at, set final_price, deduct final_price from passenger wallet_balance, insert a payment wallet_transaction for the passenger, insert a driver_earnings row with amount = final_price * 0.15 and status confirmed, set driver status to online. Insert RIDE_COMPLETED event. Emit ride:completed to passenger with final_price. Auth: driver.
PATCH /driver/rides/:id/cancel — only if status is driver_assigned or driver_arrived. Set cancelled, set driver status to online. Insert RIDE_CANCELLED event. Emit ride:cancelled to passenger. Auth: driver.
